## How do I change this app?

### Use Chantan (recommended — no coding)

Open [your project in Chantan](https://chantan.studio/dashboard/project/4f7cb80a-c353-4e9b-92a5-e838b4bf92f9) and just describe the change in chat.
You can edit text, colours and photos directly on the preview too.
When you are happy, press **Publish** — your live site updates.

### Use your own editor

You need [Node.js](https://nodejs.org) installed. Then:

```bash
# 1. Clone this repository
git clone https://github.com/as-nase/kinetix-v2.git

# 2. Go into the folder
cd kinetix-v2

# 3. Install the dependencies
npm install

# 4. Start it locally (opens at http://localhost:5173)
npm run dev
```

### Edit a file straight on GitHub

Open any file above, click the ✏️ pencil, make your change and commit it.

> **⚠️ One-way sync.** Chantan pushes to GitHub, not the other way around.
> Files **Chantan wrote** are refreshed on every sync, so edits you make to
> them here are replaced. Files **you add yourself** are left alone.
